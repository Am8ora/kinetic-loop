Kinetic Loop

Kinetic Loop is a YouTube Shorts channel of satisfying physics simulations: balls escaping rings, color battles, marble races and chain reactions. Every video, including its audio, is generated from original code for a general audience.

The Kinetic Loop app

The Kinetic Loop app is a private tool that the channel's operator uses to run this one channel. With the operator's permission through Google sign-in, it uses YouTube API Services to:

  • upload videos to the Kinetic Loop channel, with their titles and descriptions
  • read that channel's video details and performance statistics, to decide which videos to make next

It isn't offered to the public, and it doesn't access anyone else's channel or account.
