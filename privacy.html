Privacy Policy

Last updated: November 3, 2026

This policy explains how the Kinetic Loop app handles data. The app is a private tool used only by the operator of the Kinetic Loop YouTube channel, to run that channel.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

After the channel's owner grants permission through Google sign-in, the app accesses:

  • basic details of the Kinetic Loop channel and its videos, such as IDs, titles and descriptions
  • performance statistics for that channel's videos, such as views, average view percentage, likes and subscribers gained
  • permission to upload videos to that channel

The app is not designed to collect personal information about viewers. The statistics it uses are totals for each video, not details about individual people.

How the data is used

The data is used only to upload the channel's videos and to review how they perform, so the operator can decide what to make next. It is not sold, and it is not used for advertising.

Storage and sharing

  • Sign-in credentials: the access tokens that let the app reach YouTube are held by Composio, the third-party service that connects the app to YouTube, and in private configuration files on the operator's own systems.
  • Statistics and video records: these are kept in the operator's private project files.

Data is not shared with anyone else, except where the law requires it. These records are kept for as long as they are useful for running the channel, or until deletion is requested.

Removing access and deleting data

The channel's owner can remove the app's access at any time from the Google security settings page. To ask for stored data to be deleted, use the contact address below.

This website

This website sets no cookies of its own and uses no analytics. It is hosted on GitHub Pages, and GitHub may log technical information such as IP addresses to run its service.

Children

The app is not directed at children, and it does not knowingly collect personal information from them.

Changes

If this policy changes, the new version will be posted on this page with a new date.
